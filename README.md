# Riverside Social App

A new project for building the Riverside social app.

Role in the Four-Product Suite: It serves as the staff-facing content creation tool designed to solve inconsistent social media posting. It takes details about books or upcoming events from the shared catalog datasets, generates short, ready-to-use social media captions and post ideas, and logs the output for the store's social platforms.
